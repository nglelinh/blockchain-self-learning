# Blockchain Technology Course - Comprehensive Learning Path

Một khóa học toàn diện về công nghệ Blockchain, từ các khái niệm cơ bản đến chủ đề nâng cao, được thiết kế theo phong cách giảng dạy của giáo sư đại học với độ sâu về lý thuyết, toán học, và thực hành.

Các bài **00.99–07.99** là lộ trình *tùy chọn* (2022–2026): EIP, paper, L2/ZK production. Chúng **không** viết lại lý thuyết. Track tiếng Anh chưa có chương nội dung — bài tùy chọn hiện chỉ có tiếng Việt.

## 📚 Cấu trúc khóa học

### Chapter 00: Nền Tảng Blockchain
**Mục tiêu**: Hiểu các building blocks cơ bản của blockchain technology

- ✅ **Lecture 00.00**: Giới thiệu về Blockchain và Distributed Ledgers
  - Tổng quan về blockchain, double-spending problem
  - Cấu trúc block, Merkle trees, distributed ledger technology
  
- ✅ **Lecture 00.01**: Distributed Systems và Consensus Theory  
  - Byzantine Fault Tolerance, CAP theorem
  - PBFT, Nakamoto consensus, FLP impossibility
  - Implementation examples

- ✅ **Lecture 00.02**: Cryptographic Hash Functions
  - SHA-256 algorithm chi tiết với mathematical proofs
  - Collision resistance, pre-image resistance
  - Merkle trees, quantum computing threats

- ✅ **Lecture 00.03**: Digital Signatures và Public-Key Cryptography
  - ECDSA trên secp256k1, elliptic curve cryptography
  - Key generation, signing, verification
  - Bitcoin transaction signing, security considerations

- ⚪ **Lecture 00.99** *(tùy chọn)*: Ứng dụng 2022–2026 — Verkle/KZG, EIP-4844 blobs, BLS, EIP-4337/7702. Không viết lại lý thuyết hash/chữ ký.

### Chapter 01: Bitcoin - Architecture và Proof-of-Work
**Mục tiêu**: Hiểu sâu về Bitcoin - blockchain đầu tiên và quan trọng nhất

- ✅ **Lecture 01.00**: Bitcoin Architecture
  - Lịch sử và động lực phát triển Bitcoin
  - Network architecture, transaction structure
  - UTXO model, Script language, block structure

- 🔄 **Lecture 01.01**: Proof-of-Work Deep Dive
  - Mining process chi tiết, difficulty adjustment
  - Security analysis, 51% attack economics
  - Mining pools, hardware evolution

- 🔄 **Lecture 01.02**: Bitcoin Economics và Game Theory
  - Monetary policy, halving schedule
  - Incentive mechanisms, fee market
  - Game-theoretic security

- ⚪ **Lecture 01.99** *(tùy chọn)*: BIP-324, BitVM/BitVM2, inscriptions, assumeUTXO.

### Chapter 02: Advanced Consensus Mechanisms
**Mục tiêu**: So sánh các cơ chế đồng thuận khác nhau

- 📝 **Lecture 02.00**: Proof-of-Stake (PoS)
  - PoS fundamentals, validator selection
  - Nothing-at-stake problem, slashing
  - Ethereum 2.0, Cardano implementations

- 📝 **Lecture 02.01**: Byzantine Fault Tolerant Consensus
  - PBFT algorithm chi tiết
  - Tendermint, HotStuff
  - Permissioned blockchain consensus

- 📝 **Lecture 02.02**: Hybrid và Alternative Consensus
  - Proof-of-Authority (PoA)
  - Delegated Proof-of-Stake (DPoS)
  - Proof-of-Space, Proof-of-History

- ⚪ **Lecture 02.99** *(tùy chọn)*: The Merge, MEV-Boost/PBS, Pectra staking (EIP-7251/7002), CometBFT.

### Chapter 03: Ethereum và Smart Contracts
**Mục tiêu**: Hiểu Ethereum - world computer platform

- 📝 **Lecture 03.00**: Ethereum Architecture
  - Ethereum vs Bitcoin differences
  - Accounts vs UTXO, state model
  - Network structure, clients

- 📝 **Lecture 03.01**: Ethereum Virtual Machine (EVM)
  - EVM architecture, opcodes
  - Gas mechanism, execution model
  - Smart contract bytecode

- 📝 **Lecture 03.02**: Solidity và Smart Contract Development
  - Solidity language fundamentals
  - Contract patterns, security best practices
  - Testing và deployment

- 📝 **Lecture 03.03**: DeFi Protocols
  - Uniswap, Aave, Compound mechanics
  - AMMs, lending protocols
  - Yield farming, liquidity mining

- ⚪ **Lecture 03.99** *(tùy chọn)*: Dencun opcodes, ERC-4337, EIP-7702, Uniswap v4, ERC-4626, Foundry.

### Chapter 04: Blockchain Scalability
**Mục tiêu**: Giải quyết blockchain trilemma

- 📝 **Lecture 04.00**: Scalability Problem Analysis
  - Blockchain trilemma
  - Throughput vs decentralization vs security
  - Measurement metrics

- 📝 **Lecture 04.01**: Layer 2 Solutions
  - State channels (Lightning Network)
  - Sidechains (Polygon, Arbitrum)
  - Rollups (Optimistic, ZK-Rollups)

- 📝 **Lecture 04.02**: Sharding
  - Sharding fundamentals
  - Ethereum sharding design
  - Cross-shard communication

- ⚪ **Lecture 04.99** *(tùy chọn)*: EIP-4844, OP fault proofs / Stage 1, Arbitrum BoLD, zkEVM, PeerDAS.

### Chapter 05: Privacy và Security
**Mục tiêu**: Hiểu privacy techniques và security considerations

- 📝 **Lecture 05.00**: Blockchain Privacy
  - Privacy limitations in public blockchains
  - Mixing services, CoinJoin
  - Monero, Zcash approaches

- 📝 **Lecture 05.01**: Zero-Knowledge Proofs
  - ZKP fundamentals
  - zk-SNARKs, zk-STARKs
  - Applications in blockchain

- 📝 **Lecture 05.02**: Smart Contract Security
  - Common vulnerabilities (reentrancy, overflow)
  - Formal verification
  - Audit practices

- ⚪ **Lecture 05.99** *(tùy chọn)*: Nova folding, zkVM (RISC Zero, SP1, Jolt), FIPS 203–205.

### Chapter 06: Interoperability
**Mục tiêu**: Kết nối các blockchain khác nhau

- 📝 **Lecture 06.00**: Cross-Chain Communication
  - Interoperability challenges
  - Atomic swaps
  - Hash time-locked contracts (HTLCs)

- 📝 **Lecture 06.01**: Blockchain Bridges
  - Bridge architectures
  - Trust assumptions
  - Security considerations

- 📝 **Lecture 06.02**: Polkadot và Cosmos
  - Polkadot's parachain model
  - Cosmos IBC protocol
  - Comparison với other approaches

- ⚪ **Lecture 06.99** *(tùy chọn)*: IBC v2 / Eureka, CCIP, LayerZero v2, ERC-7683 intents.

### Chapter 07: Advanced Topics
**Mục tiêu**: Các chủ đề tiên tiến và tương lai

- 📝 **Lecture 07.00**: DAOs (Decentralized Autonomous Organizations)
  - DAO architecture và governance
  - Voting mechanisms
  - Case studies

- 📝 **Lecture 07.01**: NFTs và Digital Ownership
  - NFT standards (ERC-721, ERC-1155)
  - Use cases beyond art
  - Technical implementation

- 📝 **Lecture 07.02**: Web3 và Decentralized Infrastructure
  - Web3 vision và components

- 📝 **Lecture 07.03**: Quantum-Resistant Blockchains
  - Quantum computing threats
  - Post-quantum cryptography
  - Migration strategies

- ⚪ **Lecture 07.99** *(tùy chọn)*: restaking, ERC-6551, inclusion lists / ePBS, ML-KEM.

## 🎓 Phương pháp học tập

Mỗi bài giảng được thiết kế theo cấu trúc:

1. **Concept Overview** - Giới thiệu động lực và bối cảnh lịch sử
2. **Intuitive Understanding** - Giải thích qua analogies và examples
3. **Technical Foundation** - Chi tiết thuật toán, protocols, cấu trúc
4. **Mathematical Formulation** - Công thức toán học với giải thích đầy đủ
5. **Implementation Insight** - Code examples (Python/Solidity)
6. **Common Challenges** - Vấn đề thực tế, attacks, trade-offs
7. **Related Concepts** - Liên kết với các khái niệm khác
8. **Fundamental Papers** - Các bài báo nghiên cứu quan trọng
9. **Visual References** - Diagrams, interactive tools
10. **Summary** - Tóm tắt các điểm chính
